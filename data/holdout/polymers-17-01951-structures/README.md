# Polymers 2025, 17, 1951 Structure Extraction

Source paper:

> Ponomareva et al., "Furan-Urethane Monomers for Self-Healing Polyurethanes",
> Polymers 2025, 17, 1951, DOI 10.3390/polym17141951.

This folder contains only chemical-structure extraction for external validation.
No numerical property data from the paper are copied into the training directory,
and the paper is marked `used_for_training=false` in `structure_registry.csv`.
